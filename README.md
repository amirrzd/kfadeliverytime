# KFA Delivery Time

ماژول **KFA Delivery Time** برای PrestaShop، مربوط به مدیریت زمان تحویل سفارش‌ها است.

## درباره این انتشار

توسعه‌دهنده اصلی این ماژول، **مجتبی ملائکه (Mojtaba Malaekeh)** از مجموعه **Systemiha / Kolbeh Fanavari** بود. متأسفانه ایشان چند سال پیش درگذشتند.

این ماژول سال‌ها توسط کاربران و فروشگاه‌های مختلف استفاده شده و بعد از درگذشت توسعه‌دهنده اصلی نیز همچنان کاربرانی داشته که به آن وابسته بوده‌اند. با توجه به اینکه چندین سال از آن زمان گذشته و نسخه موجود عملاً بدون نگهداری رسمی باقی مانده بود، تصمیم گرفتم کدی که در اختیار داشتم را به‌صورت **رایگان و عمومی** منتشر کنم تا برای کاربران فعلی قابل دسترسی، بررسی و نگهداری باشد.

امیدوارم انتشار این کد، هم برای حفظ اثری که از توسعه‌دهنده اصلی باقی مانده و هم برای کاربرانی که هنوز از این ماژول استفاده می‌کنند، تصمیم درستی باشد.

## اعتبار

تمام اعتبار توسعه اصلی این ماژول متعلق به **مجتبی ملائکه** و **Systemiha** است.

من نویسنده اصلی این ماژول نیستم و هیچ ادعایی نسبت به تألیف اولیه آن ندارم.

## وضعیت این مخزن

این مخزن به‌صورت عمومی و بدون دریافت هزینه از طرف من در دسترس قرار گرفته است. هدف اصلی از انتشار آن، حفظ دسترسی کاربران قدیمی و جلوگیری از از بین رفتن کدی است که سال‌ها مورد استفاده بوده است.
